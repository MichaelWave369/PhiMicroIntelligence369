# Phase 12: generalization and resource lab
[Phase 11 pilot](https://github.com/MichaelWave369/PhiMicroIntelligence369/actions/runs/45331929779) / [aggregate](https://github.com/MichaelWave369/PhiMicroIntelligence369/actions/runs/45331929779/artifacts/14892601217): flat fit 80.25%, test 8.42%; learned nested fit 76.23%, test 5.72%; random nested test 6.06%; learned nested test NLL 2.716 vs flat 2.760. No superiority on exact match. Geometry/music/astronomy clustered together across all three seeds. Generalization gap motivates a diagnostic before more topology work.

Four dense character-transformer controls trained from scratch on identical known facts, with 4,800 sampled examples each at pilot budget. Raw32 uses 108 fit questions; Aug32 and Aug64 use those plus four additional templates per known fact (324 texts); Canonical32 uses 54 domain: subject prompts. Raw32/Aug32/Canonical32 use 23,744 parameters; Aug64 uses 63,872 parameters. Same examples, not identical token counts/FLOPs. No new training facts or test examples. Canonical normalizer uses only known training subjects and lexical/learned domain routes; unknown or ambiguous matches abstain. It is a deliberately strong structured input intervention, not open-domain semantic understanding. Its explicit lookup control uses the identical normalization, so we can see whether a neural component adds anything. Original reference baseline also reported.

Fresh evaluation: 54 newly authored question texts (27 known subjects, 18 held subjects, 9 invented unknowns); same underlying facts where applicable, no external evaluator or independent fact corpus, not blinded. Original 99 and fit 108 also reported. Questions are intentionally varied and include cues absent from older templates. Exact match, coverage and split results; unknown abstention explicitly scored, neural blank outputs remain unverified rather than abstain. Canonical abstention on held subjects is expected and scored incorrect. No claim that augmentation solves unseen fact recall.
