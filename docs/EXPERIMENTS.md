# Experiment protocol
Hypothesis: task-specialized small models with a routing layer can improve accuracy or cost on a fixed domain mixture, relative to a matched-resource monolith. This is not established.
Compare (A) deterministic reference/algorithm baseline, (B) one Tiny 2.1 model, (C) independently trained specialists plus router, (D) a matched-total-parameter monolith, and later (E) defined alternative architecture. No claims for C–E until implemented.
Use preregistered held-out facts, paraphrase families, unknown entities and compositional prompts, with fixed seeds, exact or human-reviewed answers, and separate routing errors. Report per-domain accuracy, coverage, selective accuracy, false answers on unknowns, bytes, peak memory, median/p95 latency, training compute and energy where measured. Count router, memory and duplicated weights in all budgets. Publish raw results and configuration. Do not mistake character-level softmax for truth confidence.
First milestone: verify binary checksum, compare per-step logits to a reference with tolerance and greedy outputs, evaluate original model on a frozen held-out set, compare deterministic reference retrieval. Current fixture test is a smoke check only.
